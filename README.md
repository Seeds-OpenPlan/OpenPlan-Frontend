# OpenPlan Frontend

OpenPlan MVP1 프론트엔드 애플리케이션입니다.

## 기술 스택

- React
- JavaScript
- Vite
- Tailwind CSS

## 개발 환경

- Node.js 22 LTS
- npm

## 환경 변수

`.env.example`을 참고해 `.env` 파일을 생성합니다.

```env
VITE_API_BASE_URL=http://localhost:8080
```

## 설치

```bash
npm install
```

## 실행

```bash
npm run dev
```

기본 실행 주소는 아래와 같습니다.

```txt
http://localhost:5173
```

## 빌드

```bash
npm run build
```

## 주요 명령어

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
